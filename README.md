# Curriculum Vitae

This repository contains my Curriculum Vitae built using [Typst](https://typst.app/)

## Getting Started

### Prerequisites

You need to have Typst installed on your machine. You can find the installation instructions in the [official Typst repository](https://github.com/typst/typst) or use the web app.

## Project Structure

The CV's content is decoupled from its layout, making it easy to update:

- `main.typ` — The main entry point and layout configuration.
- `content/yaml/` — Contains structured data for the CV. `content/typ/` — Contains text blocks and typst content.
- `font/` — Custom fonts used to render the CV.
