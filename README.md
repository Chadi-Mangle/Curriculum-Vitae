# Curriculum Vitae (Typst × `career-ops` × `humanizer`)

This repository combines a [Typst](https://typst.app/) CV and cover-letter workflow with a streamlined `career-ops` pipeline (portal scanning, A–H offer evaluation, fact-checking, ATS keyword matching, and single-PDF ADUM dossier merging) and [`blader/humanizer`](https://github.com/blader/humanizer) to keep all generated prose natural and free of AI writing patterns.

See [WORKFLOW.md](WORKFLOW.md) for the complete step-by-step workflow.

## Prerequisites

- [Typst CLI](https://github.com/typst/typst) (`typst 0.15+`)
- Node.js (`>= 22.13`)
- Poppler utils (`pdftotext`, `pdfinfo`, `pdfunite`)

## First-Time Setup (Generate Real YAML Files from `*.example.yml`)

All personal files are gitignored. **For the first generation of your YAML files (whether edited by hand or generated by an AI agent), always inspect and copy the matching `*.example.yml` templates** so every key, metadata tag (`archetypes`, `tracks`, `tags`, `status`, `priority`), Font Awesome icon name, and validation rule matches what the scripts expect:

```bash
cp content/yaml/info.example.yml content/yaml/info.yml
for f in experience-all projects-all skills-all about-all education-all; do
  cp "content/yaml/${f}.example.yml" "content/yaml/${f}.yml"
done
cp content/typ/about.example.typ content/typ/about.typ
cp config/profile.example.yml config/profile.yml
cp portals.example.yml portals.yml
cp portals.cdi-vie.example.yml portals.cdi-vie.yml
cp modes/_profile.example.md modes/_profile.md
cp modes/_custom.example.md modes/_custom.md
npm install
make sync && make doctor
```

## Project Structure

- `main.typ` / `cover-letter.typ` — Typst templates (`@preview/lavandula:0.1.1`) reading personal identity/contact data from `content/yaml/info.yml`.
- `content/yaml/info.yml` & `content/yaml/*-all.yml` — Gitignored personal info and master CV bank. Sanitized `*.example.yml` templates are tracked in git.
- `scripts/typst/` — CV and dossier pipeline scripts (`sync-cv-md.mjs`, `select-from-bank.mjs`, `build-typst-cv.mjs`, `merge-dossier.mjs`).
- `scripts/parsers/` — Zero-token local PhD portal parsers (`doctorat-gouv.mjs`, `inria-phd.mjs`, `cnrs-phd.mjs`, `cea-theses.mjs`, `onera-theses.mjs`, `abg-theses.mjs`).
- `.agent/skills/` — Local agent skills (`typst-cv` and `humanizer`).
- `documents/` — Gitignored static PDFs merged into ADUM dossiers (`notes.pdf`, optional `recommandation.pdf`).
- `font/` — Local fonts (`Fira Sans` + `Font Awesome 7`).

## Common Commands

```bash
make scan-phd                                                     # Scan PhD & CIFRE (portals.yml)
make scan-cdi                                                     # Scan CDI France & VIE (portals.cdi-vie.yml)
make sync                                                         # Regenerate cv.md from content/yaml/*-all.yml & info.yml
make score JD=jds/example.md OUT=output/bundles/slug/selection.json
make build BUNDLE=output/bundles/slug OUT=output/001-cv-....pdf JD=jds/example.md REPORT=001
make cover LETTER=output/bundles/slug/cover-letter.yml OUT=output/001-cover-letter-....pdf
make cv                                                           # Compile default main.typ -> cv.pdf (1-page check)
make merge-dossiers                                               # Merge CV + Cover + documents/notes.pdf (+ rec)
make doctor                                                       # Validate workflow setup, profile, and portal configs
```
